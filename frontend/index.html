// Technical specs

Engineered for the bench.

LabReach connects to your existing lab network via Wi-Fi or Ethernet and communicates with instruments through a universal relay module — no instrument-specific firmware required.

A compact hardware hub installs in minutes. The rest is software.

ConnectivityWi-Fi 6 + Gigabit Ethernet
SecurityAES-256, TLS 1.3, 2FA
Latency< 50 ms typical
Power InputUSB-C, 5V / 3A
Relay Output4-channel, 10A per channel
Instruments14+ categories supported
PlatformWeb, iOS, Android
Dimensions110 × 72 × 28 mm
